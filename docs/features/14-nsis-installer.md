## Overview

A custom white-themed NSIS installer for NEXUS with branded images, custom colors, and Start Menu only (no desktop shortcut). The installer is generated by Tauri v2's bundler using a custom NSIS template.

## Custom NSIS Template

### File: `src-tauri/installer/nexus-installer.nsi`

The template is based on Tauri's default NSIS template, downloaded from:
`https://github.com/tauri-apps/tauri/dev/crates/tauri-bundler/src/bundle/windows/nsis/installer.nsi`

### Customizations

#### White Background
All installer controls are set to white background with black text:
```nsis
Function OnGuiInit
  SetCtlColors $HWNDPARENT "" "FFFFFF"
  SetCtlColors $HWNDPARENT 000000 FFFFFF
  ; Iterate through all child controls and set colors
FunctionEnd
```

The `MUI_PAGE_CUSTOMFUNCTION_GUIINIT` hook calls `OnGuiInit` before the first page appears.

#### Welcome Text
```nsis
!define MUI_WELCOMEPAGE_TEXT "NEXUS is a cross-platform, Siri-like floating desktop assistant.$\r$\n$\r$\nClick Next to continue with the installation."
```

#### No Desktop Shortcut
The `MUI_FINISHPAGE_SHOWREADME` defines were removed:
```nsis
; NEXUS: No desktop shortcut option — Start Menu only
; (MUI_FINISHPAGE_SHOWREADME defines removed)
```

The `CreateOrUpdateDesktopShortcut` function was removed entirely.

The passive/silent mode desktop shortcut creation was also removed:
```nsis
; NEXUS: No desktop shortcut — Start Menu only
; (PassiveMode/Silent desktop shortcut creation removed)
```

#### Uninstaller Cleanup
The uninstaller still removes any existing desktop shortcuts (for users upgrading from a version that created them):
```nsis
; Remove desktop shortcuts (cleanup from previous versions)
!insertmacro IsShortcutTarget "$DESKTOP\${PRODUCTNAME}.lnk" "$INSTDIR\${MAINBINARYNAME}.exe"
${If} $0 = 1
  !insertmacro UnpinShortcut "$DESKTOP\${PRODUCTNAME}.lnk"
  Delete "$DESKTOP\${PRODUCTNAME}.lnk"
${EndIf}
```

## Installer Images

### Sidebar Image (`sidebar.bmp`)
- **Size:** 220x500 pixels (larger than standard 164x314)
- **Format:** 24-bit BMP
- **File size:** ~430 KB
- **Content:**
  - White background
  - Gradient orb (blue #6AA8FF → purple #A855F7) with glow effect
  - Inner highlight on orb (semi-transparent white)
  - "NEXUS" text in gradient (22pt Segoe UI Bold)
  - "AI Desktop Assistant" subtitle (10pt Segoe UI, gray)
  - Divider line (light gray)
  - Feature list with blue dots:
    - Voice-controlled
    - Local & private
    - Cross-platform
  - "Version 0.1.0" at bottom (8pt, light gray)

### Header Image (`header.bmp`)
- **Size:** 180x68 pixels (larger than standard 150x57)
- **Format:** 24-bit BMP
- **File size:** ~48 KB
- **Content:**
  - White background
  - "NEXUS" text in gradient (16pt Segoe UI Bold)
  - Gradient bar at bottom (blue → purple, 8px tall)

### Image Generation
Both images are generated using PowerShell with System.Drawing:
```powershell
Add-Type -AssemblyName System.Drawing
$bmp = New-Object System.Drawing.Bitmap(220, 500)
$gfx = [System.Drawing.Graphics]::FromImage($bmp)
$gfx.SmoothingMode = [System.Drawing.Drawing2D.SmoothingMode]::AntiAlias
$gfx.TextRenderingHint = [System.Drawing.Text.TextRenderingHint]::AntiAlias
# ... draw orb, text, features
$bmp.Save("sidebar.bmp", [System.Drawing.Imaging.ImageFormat]::Bmp)
```

### Why Bigger Images?
NSIS auto-sizes the installer window to match the sidebar image dimensions. A 220x500 sidebar (vs the standard 164x314) makes the entire installer window larger, giving a more spacious, modern feel.

## Tauri Configuration

### `tauri.conf.json` — NSIS section
```json
{
  "bundle": {
    "windows": {
      "nsis": {
        "template": "installer/nexus-installer.nsi",
        "installerIcon": "icons/installer.ico",
        "headerImage": "installer/header.bmp",
        "sidebarImage": "installer/sidebar.bmp",
        "compression": "lzma",
        "installMode": "currentUser",
        "languages": ["English"],
        "displayLanguageSelector": false
      }
    }
  }
}
```

### Configuration Fields
| Field | Value | Description |
|-------|-------|-------------|
| `template` | `installer/nexus-installer.nsi` | Custom NSIS template with white theme |
| `installerIcon` | `icons/installer.ico` | Icon for the installer .exe |
| `headerImage` | `installer/header.bmp` | 180x68 header bitmap |
| `sidebarImage` | `installer/sidebar.bmp` | 220x500 sidebar bitmap |
| `compression` | `lzma` | Best compression ratio |
| `installMode` | `currentUser` | No admin required, installs to LocalAppData |
| `languages` | `["English"]` | English only |
| `displayLanguageSelector` | `false` | No language dropdown |

## Install Location

Since `installMode` is `currentUser`, NEXUS installs to:
```
C:\Users\<username>\AppData\Local\NEXUS\
```

This does NOT require administrator privileges.

### Installed Files
```
AppData\Local\NEXUS\
├── NEXUS.exe                    # Main Tauri binary
├── resources/
│   ├── porcupine/               # Wake word models
│   ├── sherpa/                  # Speaker verification models
│   │   ├── kws/
│   │   ├── speaker_model.onnx
│   │   └── silero_vad.onnx
│   └── whisper/                 # STT models
├── icons/                       # App icons
└── uninstall.exe                # Uninstaller
```

```nsis

!define PRODUCTNAME "{{product_name}}"
!define VERSION "{{version}}"
!define INSTALLERICON "{{installer_icon}}"
```

## Uninstaller

The uninstaller (built into the same NSIS template):
1. Confirms uninstallation
2. Optionally deletes app data (checkbox)
3. Removes all installed files
4. Removes Start Menu shortcuts
5. Removes any existing desktop shortcuts (cleanup)
6. Removes registry entries
7. Closes itself
